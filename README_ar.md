# 🤖 بوت ترجمة ملفات المحاضرات إلى العربية — دليل النشر (خطوة بخطوة)

نسخة **v9** — مُختبَرة فعلياً على **13 ملفاً** مختلفاً (PDF عادي، صفحة غلاف، عنوان أسطر، عمودان، جدول، صورة+تعليق، أفقي/أرضي، ملف عربي أصلاً، ملف طبي كثيف، Word، PowerPoint، Excel، نص) — بدون أي انهيار، مع عربية صحيحة متصلة واتجاه RTL سليم.

## 📦 محتويات الحزمة

| الملف | الوظيفة |

## ✅ ما الذي أُصلح في هذه النسخة؟

1. **العربية كانت تظهر مكسّرة (كل حرف يتبعه حرف e)** ⟶ أصبحت الآن **متصلة وصحيحة** باتجاه RTL بفضل محرك HTML/Bidi + خط Amiri.
2. **الترجمة كانت بطيئة (30 دقيقة)** ⟶ الآن **8–9 ثوانٍ لملف 11 صفحة** (دفعات + خدمة مجانية بلا مفتاح).
3. **الأخطاء 404/429 (موديلات قديمة، طلبات كثيرة)** ⟶ الموديلات تُجلب **ديناميكياً** من الـ API، مع تقسيم دفعات وإعادة محاولة وقاطع دائرة (circuit breaker).
4. **الصفحات تفشل برسالة عامة** ⟶ الآن تُترجم صفحة‑صفحة مع تقدم مباشر، ولو فشلت كل الخدمات تُستخدم ترجمة تقريبية بدل التعطّل.
5. **Phenyto** (لم تُقطع من عندنا — النص هكذا في ملفك الأصلي!)، وباقي المحتوى يُعاد بناؤه موسّعاً فلا يُقطع.
6. **الجداول/الأعمدة** تُدعم، والاختصارات الطبية (PPI, H2, GERD) تبقى إنجليزية، والتسميات الطبية مُصحّحة (مثل: مضخّة البروتون، فئة).

## 🚀 خطوات النشر على Railway (بالترتيب)

### 1) ارفع الملفات إلى GitHub
- افتح مستودعك على GitHub.
- **احذف الملفات القديمة** (أو استبدلها) وارفع: `main.py`, `translator.py`, `translate_pdf.py`, `doc_converter.py`, `requirements.txt`, `Procfile`.
- تأكد من وجود المجلد `assets/fonts/` وفيه `Amiri-Regular.ttf` و`Amiri-Bold.ttf`.
- ⚠️ **مهم جداً:** تأكد أن **Auto-Deploy مفعّل** في Railway (كان مُطفأً سابقاً فتشغّل كود قديم).

### 2) تأكد من محتوى `Procfile`
يجب أن يكون سطراً واحداً بالضبط:
```
worker: python main.py
```

### 3) في Railway
- **Settings → Deploy → Service Type** اختر **Worker** (وليس Web).
- **Variables** أضف:

| المتغير | مطلوب؟ | ملاحظة |
|---|---|---|
| `BOT_TOKEN` | ✅ نعم | توكن البوت من @BotFather. |
| `GEMINI_API_KEY` | مستحسن بشدة | يحسّن جودة المصطلحات الطبية. |
| `GROQ_API_KEY` | اختياري | خدمة بديلة. |
| `GEMINI_MODEL` | اختياري | لتثبيت موديل معيّن (يُجلب تلقائياً إن تُرك فارغاً). |
| `MAX_FILE_MB` | اختياري | الحجم الأقصى (الافتراضي 20). |

> بدون أي مفتاح يعمل البوت عبر خدمة **google-free** المجانية (جودة جيدة) و**MyMemory** كاحتياط.

### 4) ابدأ التشغيل وراقب السجلات (Logs)
ابحث عن أحد هذه السطور:
- ✅ `بدء تشغيل البوت (polling)...`
- ❌ `BOT_TOKEN غير مضبوط` ⟶ انسَ إضافة التوكن.
- ❌ `Traceback` ⟶ أرسل لي النص لأصلحه.

### 5) اختبر البوت
- أرسل `/start` ثم `/test` (يعرض الخدمات العاملة).
- أرسل ملف PDF وانتظر الناتج المترجم.

## 🎯 كيف تستخدمه؟

1. أرسل أي ملف (PDF, Word, PowerPoint, Excel, نص، صورة) — حتى 20 ميغابايت.
2. يردّ البوت بالناتج **بنفس الصيغة**، مع:
   - النص الإنجليزي الأصلي **محفوظ** كما هو.
   - الترجمة العربية **باللون الأحمر أسفل كل فقرة**.
   - الصور والإطارات الزخرفية **محفوظة**.

الأوامر: `/start` `/help` `/test` `/status`.

---

## ⚠️ حدود معروفة (كن على علم بها)

1. **PDF ممسوح ضوئياً (صور فقط)**: يحتاج OCR — أخبرني لأضيفه.
2. **ملف عربي أصلاً**: يُترك كما هو (لا يُترجم) لأن الاتجاه عربي.
3. **الحجم الأقصى**: 20 ميغابايت افتراضياً (غيّره بـ `MAX_FILE_MB`).
4. **الخدمة المجانية**: قد تبطؤ أحياناً تحت الضغط؛ إضافة `GEMINI_API_KEY` ترفع الجودة والسرعة.

## 🔧 ملاحظات للمطوّر

- ترتيب الخدمات: `Gemini → Groq → google-free → MyMemory → Google → LibreTranslate`.
- كل خدمة تفشل مرّتين تُوقف مؤقتاً 240 ثانية (قاطع دائرة) ثم تُعاد.
- قبل الرسم يُفحص كل حرف مقابل خط Amiri (لمنع المربعات الفارغة □).
- حماية جديدة: لو أعادت خدمة النص الإنجليزي دون ترجمة، تُعتبر فاشلة ويُجرَّب غيرها.
